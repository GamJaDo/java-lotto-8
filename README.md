# java-lotto-precourse

구현할 기능 목록
=============
* * *
## 1. 로또를 구매한다.
 - [x] 로또 구입금액 입력
    - 로또 구입금액이 숫자로 입력받았는지 확인
    - 로또 구입금액이 1,000원으로 나누어 떨어 지는지 확인
 - [ ] 로또 번호리스트들을 출력 
    - 입력한 구입금액 만큼 출력
    - 오름차순으로 출력

## 2. 당첨 번호와 보너스 번호를 입력한다.
 - [ ] 당첨 번호 6자리 입력
   - 쉼표(,) 구분자가 있는지 확인
   - 당첨 번호가 6자리인지 확인
   - 당첨 번호가 숫자로 이루어져 있는지 확인
   - 당첨 번호들의 범위가 1~45인지 확인
   - 당첨 번호 6개가 서로 중복인지 확인
 - [ ] 보너스 번호 입력 
   - 보너스 번호가 숫자로 입력받았는지 확인 
   - 보너스 번호의 범위가 1~45인지 확인

## 3. 당첨 현황을 출력한다.
 - [ ] 로또 번호 리스트들과 당첨 번호를 비교
 - [ ] 당첨 현황을 매김
 - [ ] 당첨 현황 출력

## 4. 총 수익률을 계산한다.
 - [ ] 총 수익률 계산
 - [ ] 총 수익률 출력
